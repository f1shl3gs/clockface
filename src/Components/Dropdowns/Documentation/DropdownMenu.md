# Dropdown Menu

DropdownMenu is part of the Dropdown component family and can be accessed from the single import. We recommend passing in children of type `<DropdownItem />` or `<DropdownDivider />` for best results.

### Usage
```tsx
import {Dropdown} from '@influxdata/clockface'

<DropdownMenu />
```
