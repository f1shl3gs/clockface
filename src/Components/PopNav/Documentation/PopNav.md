# Pop Nav

A Popover based navigation menu.

### Usage

```tsx
import {PopNav} from '@influxdata/clockface'
```

```tsx
<PopNav>
  // Some content
  <PopNavItem>item 1</PopNavItem>
  <PopNavItem>item 2</PopNavItem>
  <PopNavItem>item 3</PopNavItem>
</PopNav>
```
